For developers

Atlas is itself an open agentic website. Your agents can use it three ways.

Call Atlas's network

Add Atlas's network URL to an agent's tools and its origin to your allowed_peers. Your visitor agrees on a card, then Atlas's agent runs in their browser on their own key.

Use the MCP server

Three read-only tools: search_directory, check_site and list_sites. Streamable HTTP, plain JSON, CORS open.

Show a badge

Put your live Atlas result in a README. It updates every few minutes.

JSON API: /api/check?url= and /api/directory?q=. Checks follow MVP Profile 0.2 and use the reference runtime's own validator. Source on GitHub (Apache 2.0).

Agent Atlas checks public files only. A clean report means the files follow the spec and nothing obvious is wrong, not that a site's agents are safe to trust with anything.
